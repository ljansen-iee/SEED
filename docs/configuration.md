# Configuration

## Transport — `trans_config.csv`

Located at `transport/trans_config.csv`. The file is auto-generated by
`transport/build_transport_config.py` and can be hand-edited afterwards to
override default CAGR values for specific countries.

The file uses a **wide format**: each row describes one assumption
(type + metric + milestone year + scenario) and each country occupies its own
column. A `default` column holds the fallback value used when no country-specific
override is supplied.

| Column | Type | Description |
|--------|------|-------------|
| `Assumption Type` | string | `CAGR` (growth rate) or `Target` (absolute milestone value) |
| `Metric Name` | string | Metric key (e.g. `Mobility per capita - Passenger`, `Energy Intensity - LDV ICE`) |
| `Year` | int | Milestone year: 2030, 2035, 2040, 2045, or 2050 |
| `Scenario` | string | `BAU`, `Progressive`, or `Optimistic` |
| `default` | float | Value used for any country without an explicit column override |
| `{Country}` | float | Per-country override; one column per country in the model |

**Example** — CAGR for passenger mobility per capita in the BAU scenario for
milestone year 2030, with a Morocco-specific value:

```csv
Assumption Type,Metric Name,Year,Scenario,default,Morocco,Egypt,...
CAGR,Mobility per capita - Passenger,2030,BAU,0.0183,0.0316,0.0183,...
```

## Residential — in-code constants

Residential configuration is currently defined as Python variables inside
`residential/build_residential_config.py`:

```python
BASE_YEAR      = 2018
SCENARIOS      = ["Current Policies", "Progressive", "Ambitious Net Zero"]
SSP_ORDER      = ["SSP2", "SSP2", "SSP1"]
GROWTH_PATHWAY = "moderate"   # "low" | "moderate" | "high"
```

!!! warning "Work in progress"
    A dedicated config file (CSV or YAML) for the residential module is planned
    but not yet implemented.

## Root-level CAGRs — `build_CAGR.py`

The root `build_CAGR.py` computes rolling 5-year CAGRs from UNSD historical
totals. These are consumed by the additional-sectors module. The sector labels
and base period are defined as constants inside the script:

```python
BASE_PERIODS = [2011, 2015, 2019]
DEFAULT_SECTOR_LABELS = { ... }   # UNSD → internal sector name mapping
```

## Industry — `industry_config.csv`

Located at `industry/industry_config.csv`. The file is auto-generated by
`industry/build_config_industry.py` and can be hand-edited afterwards to
override default values for specific countries.

Like the transport config, the file uses a **wide format**: each row describes
one assumption and each country occupies its own column.

| Column | Type | Description |
|--------|------|-------------|
| `Assumption Type` | string | `CAGR` (growth rate applied between milestone years) or `SHARE` (direct share override at a milestone year) |
| `Metric Name` | string | Metric key (e.g. `Steel production per year`, `BF+BOF share`, `Electricity intensity - Cement`) |
| `Year` | int | Milestone year: 2030, 2035, 2040, 2045, or 2050 |
| `Scenario` | string | `BAU`, `Progressive`, or `Optimistic` |
| `default` | float | Value used when no country-specific column is provided |
| `{Country}` | float | Per-country override; columns present for Morocco, Egypt, South Africa |

**Example** — CAGR for steel production in the BAU scenario by 2035, and a
share override for the DR+EAF process in the Optimistic scenario by 2040:

```csv
Assumption Type,Metric Name,Year,Scenario,default,Morocco,Egypt,South Africa
CAGR,Steel production per year,2035,BAU,0.0,0.0,0.0,0.0
SHARE,DR+EAF share,2040,Optimistic,0.35,0.4,0.3,0.35
```
